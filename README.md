
This project was built to practice building a real-world e-commerce UI as a student learning frontend web development.

## 📁 Pages Included

| Page | Description |
|---|---|
| 🏠 Home | Landing page with product showcase |
| 🛍️ Products | Product listing with filters |
| 🛒 Cart | Shopping cart functionality |
| 📄 Product Detail | Individual product page |
| 📞 Contact | Contact form page |

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
